# PLAN-IT

Plant recommendation app (React Native + Flask) built around Texas A&M
Earth-Kind plant data.

- **Backend** (API, Docker, tests): see [`Backend/README.md`](Backend/README.md)
- **Frontend**: Expo / React Native under `Frontend/`

> Note: Firebase config files (`google-services.json`, `GoogleService-Info.plist`)
> were historically committed. They are gitignored now — rotate keys if this
> repo was shared, and do not re-add them.
